# Java Console Calculator

## 📌 Objective
A simple Java console-based calculator that performs:
- Addition
- Subtraction
- Multiplication
- Division (with divide-by-zero handling)

## 🛠 Tools
- Java (JDK)
- VS Code / IntelliJ IDEA / Command Prompt
